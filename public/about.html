Questions

What is 150ct?

150ct is a set of free, small web tools for getting together: a potluck sign-up sheet, a poll to find a day that works, a way to send the group a few places to eat, a gift exchange name drawer, and a gift registry from any store. Each one works from a single link.

Is it free? Do I need an account?

Yes, it's free, with no ads. Nobody needs an account or an app, not the host and not the guests. You make a link and send it to your group chat.

How long do links last?

Links delete themselves automatically, generally 30 days after the event date. The host can delete a link sooner.

How do I draw names for Secret Santa without anyone seeing?

Use Gift exchange at 150ct.com/gift. Type everyone's name, add an optional budget and date, and the names are drawn right away. Send the one link to the group. Each person taps their own name to see who they're buying for. Nobody else, including the organizer, can see the pairs.

How do I make a gift registry with things from different stores?

Use Registry at 150ct.com/registry. Paste links from any store, like Amazon, Target or Etsy, add a price if you want, and send the one link. Guests tap the gift they'll get, and it shows as taken for everyone else so nothing is bought twice. Turn on surprise if you don't want to see what's been claimed.

How do I make a potluck sign-up sheet?

Use Potluck at 150ct.com/potluck. List the dishes you need, or start from a template like Thanksgiving, and send the link. Guests claim a dish, and each dish can only be claimed once, so nothing gets doubled.

How do I find a day that works for a group?

Use When works at 150ct.com/meet. Pick the possible days, and hours if you want, and send the link. Everyone taps when they're free, and the best day so far shows at the top.

How do I send friends a few restaurant options?

Use Where to eat at 150ct.com/eat. Search for places or paste Google Maps links, tick the ones you want, and send one text with all the map links.
